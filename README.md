### CanvasRelay

[CanvasRelay](https://github.com/daviLeedev/CanvasRelay)는 AI 이미지 작업을 위한 크리에이티브 스튜디오를 공개 포트폴리오 형태로 재구성하는 프로젝트입니다.

프롬프트, 레퍼런스 이미지, 생성 설정을 하나의 작업 흐름으로 관리하고, 작업 상태·결과·재시도·라이브러리를 일관된 UI에서 다루는 것을 목표로 합니다. 현재 Flask 기반 로컬 스튜디오의 경험을 Next.js + FastAPI 구조로 단계적으로 마이그레이션하고 있습니다.

- Provider-neutral image job orchestration
- Durable job metadata and media-library architecture
- Image generation and image-edit workflows
- Responsive studio shell with 2D/3D stage exploration
- Typed API contracts, tests, and local-first provider integration
- Credentials, local models, and generated media are excluded from the public repository

### ANA Content OS

[![GitHub](https://img.shields.io/badge/GitHub-ANA-181717?style=for-the-badge&logo=github)](https://github.com/daviLeedev/ANA)
![Status](https://img.shields.io/badge/Status-In_Development-E5A50A?style=for-the-badge) ![Local First](https://img.shields.io/badge/Architecture-Local_First-2E7D32?style=for-the-badge)

AI 인플루언서의 세계관, 생성, 검수, SNS 배포와 성과를 관리하는 로컬 퍼스트 ContentOps 플랫폼입니다.

`Trend → Persona Canon → Brief → Script → Storyboard → Generation → Review → Publishing`

### 주요 기능
- 구조화된 Persona 설정과 승인된 Visual Canon 관리
- Reels·TikTok·YouTube 참고 영상 분석 및 ANA 스타일 재해석
- Higgsfield Generation Bridge와 생성 Asset 계보 관리
- YouTube·Instagram·TikTok 배포 및 Discord 원격 운영
